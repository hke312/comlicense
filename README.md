# 컴퓨터활용능력 2급 실기 채점 프로그램 (`comlicense-grader`)

대한상공회의소 컴퓨터활용능력 2급 실기 시험의 영역별 배점 및 부분점수 기준을 반영한 웹 기반 자동 채점 · 학생 점수 이력 · 점수 분포 통계 · 채점기준 안내 프로그램입니다.

## 주요 화면 구성

1. **채점프로그램 Home (`/`)**
   - 회차 선택 및 문제 파일(`.xlsm`) · 문제지(`HTML`) 개별/전체(ZIP) 다운로드
   - 학생 로그인/회원가입 모달 및 비식별 닉네임·선생님 코드 입력, 답안 파일(`.xlsx`, `.xlsm`) 업로드 및 즉시 채점
   - 작업별 상세 점수(문제1~4) 및 총점(70점 이상 합격 판정), 감점 내역 및 분석 표
   - 학생/선생님 누적점수 순위 차트, 동영상 강좌 안내 모달, 인쇄 기능
2. **내 점수 이력 (`/history`)**
   - 로그인한 학생 계정의 회차별 응시 횟수, 합격률, 최고 점수, 평균 점수 KPI
   - 회차별 채점 기록 표 및 과거 채점 건별 감점 상세 모달
3. **점수별 통계보기 (`/statistics`)**
   - 해당 회차 총점수 비율 및 문제 1~4별 점수 구간 분포 SVG 파이 차트
   - 채점 후 이동 또는 로그인 상태에서 내 점수 구간(`[내 점수]`) 자동 강조 및 접근성 데이터 표 제공
4. **채점기준 및 도움말 (`/criteria`, `/help`)**
   - 100점 만점 / 70점 합격 기준 및 영역별 부분점수/전부감점 규칙 안내
   - 실시간 합격 점수 시뮬레이터 및 제출 안내 FAQ

## 개인정보 비저장(PII-free) 설계

- 이메일, 전화번호, 실명을 직접 수집·저장하지 않고 영문/숫자 기반 학습용 `login_id`와 `display_nickname`만 사용합니다.
- 비밀번호는 솔트 적용 `scrypt` 해시로, 세션 토큰은 SHA-256 해시로만 저장하며 `HttpOnly` 쿠키를 사용합니다.
- 업로드한 엑셀 파일의 원본 파일명(실명·학번 포함 가능성)은 DB에 저장하지 않고 확장자(`.xlsx`/`.xlsm`)만 기록합니다.

## 영역별 배점 기준

- **문제1 기본작업 (20점)**: 기본작업-1(5점, 부분점수 없음) / 기본작업-2(10점, 2점×5 부분점수 있음) / 기본작업-3(5점, 부분점수 없음)
- **문제2 계산작업 (40점)**: 함수 5문제(각 8점, 부분점수 없음, 결과값 일치 시 수식 구조·셀 참조 무관 정답 인정)
- **문제3 분석작업 (20점)**: 피벗테이블·시나리오·목표값 찾기·통합 등 2문제(각 10점, 부분점수 없음, 오류 시 전부 감점)
- **문제4 기타작업 (20점)**: 매크로 작업 2문제(각 5점, 기록·버튼 연결 부분점수 있음) / 차트 작업 5문항(각 2점, 세부 지시사항별 부분점수 있음)

## 환경 변수 및 Supabase 연동

기본적으로 `.env`에 `SUPABASE_URL`과 `SUPABASE_SERVICE_ROLE_KEY`가 설정되어 있으면 Supabase(PostgreSQL REST)에 저장하며, 미설정 시 로컬 SQLite(`data/comlicense.db`)로 자동 동작합니다.

```powershell
# .env.example을 복사해 .env 작성
Copy-Item .env.example .env
```

- `SUPABASE_URL`: Supabase 프로젝트 URL
- `SUPABASE_ANON_KEY`: Supabase 익명 공개 키
- `SUPABASE_SERVICE_ROLE_KEY`: 서버 전용 Service Role 키 (**절대 Git에 커밋하지 마세요**)
- `COMLICENSE_COOKIE_SECURE`: 로컬 HTTP 개발 시 `false`, 운영 HTTPS 배포 시 `true`

## 실행 방법

```powershell
# 서버 실행 (http://127.0.0.1:8000)
uv run comlicense-grader

# 또는 개발 모드
uv run uvicorn comlicense_grader.main:app --reload
```
