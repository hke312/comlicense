대표기출따라하기 문제지

시험시간: 40분 · 총점: 100점 (70점 이상 합격) · 실습 파일: 대표기출따라하기_실습파일.xlsm

수험자 유의사항: 제공된 실습 엑셀 파일(.xlsm)을 열어 각 시트명(기본작업-1 ~ 차트작업)에 지시된 작업을 수행한 뒤, 반드시 저장(Ctrl+S)하여 닫은 파일을 채점 화면에 업로드하세요.

문제 1. 기본작업 총 20점

1. [기본작업-1] 데이터 입력 (5점 · 부분점수 없음)

기본작업-1 시트의 A3:F8 영역에 아래 표의 데이터를 정확히 입력하세요.

구분 (A3) 제품명 (B3) 판매수량 (C3) 단가 (D3) 매출액 (E3) 비고 (F3)
가전공기청정기12035000042000000인기상품
가전무선청소기8548000040800000정상
생활전기포트2106500013650000특가
생활스팀다리미1408900012460000정상
주방에어프라이어16514500023925000인기상품

2. [기본작업-2] 셀 서식 지정 (10점 · 각 2점 부분점수 있음)

기본작업-2 시트(상공 정육식당 소고기 판매 현황)에 다음 지시사항을 적용하세요.

  1. A1:F1 영역을 병합하고 가운데 맞춤한 뒤, 글꼴 크기를 14pt 이상·굵게(Bold)로 지정하세요.
  2. A3:F3 머리글 영역에 채우기 색(음영)을 지정하고, A3:F15 표 전체에 테두리를 적용하세요.
  3. 종류 열의 동일 품목 셀(A4:A6, A7:A9, A10:A12, A13:A15)을 각각 병합하세요.
  4. 사용자 지정 표시 형식을 적용하세요: D4:D15 및 F4:F15에는 천 단위 구분 기호/통화 형식(예: #,##0 또는 ₩#,##0), E4:E15에는 숫자 뒤에 kg가 표시되도록(예: 0"kg") 설정하세요.
  5. F4:F15 영역의 이름을 총판매금액으로 정의하세요. (또는 해당 영역에 조건부 서식 적용)

3. [기본작업-3] 고급 필터 / 조건부 서식 (5점 · 부분점수 없음)

기본작업-3 시트(상공 포장이사 예약 현황)에서 아래 작업 중 지시된 조건을 수행하세요.

  • A3:H16 데이터 목록에서 조건에 맞는 데이터를 고급 필터를 이용하여 A22 셀 위치부터 추출하거나, A4:H16 범위에 행 전체 조건부 서식을 적용하세요.

문제 2. 계산작업 총 40점 (각 8점 · 부분점수 없음)

※ 계산작업은 결과값이 정답과 일치하면 함수식의 세부 구조나 셀 참조 방식($ 사용 여부 등)이 달라도 정답으로 인정됩니다.

  1. [표1] 셔틀버스 운행 시간표 (D3:D10): 출발시간(C3:C10)에 정류장수(B3:B10) × 6분(예: =C3+TIME(0,B3*6,0))을 더하여 도착시간을 계산하세요.
  2. [표2] 영업부서별 실적표 (J3:J10): 소속(F3:F10), 매장위치(H3:H10), 판매실적(I3:I10)을 참조하여 IF, AND, OR 등의 함수로 비고를 구하세요. (예: 판매실적이 5000 이상이면 "우수", 아니면 "보통")
  3. [표3] 영화예매현황 (D24): 조건 범위(E22:E23) 또는 조건 함수를 이용해 장르가 "드라마"인 영화들의 예매수량 평균(21881.25)을 구하세요. (DAVERAGE, AVERAGEIF 등)
  4. [표4] 아파트 당첨현황 (J14:J24): 최저층(H14:H24)과 최고층(I14:I24) 사이의 임의의 정수로 당첨층수를 구하세요. (RANDBETWEEN(H14, I14) 등)
  5. [표5] 자격증 수강등록 현황 (E28:E37): 수강코드(B28:B37)의 구분 문자를 추출해 CHOOSE, MID, IF 등의 함수로 수강과목명을 표시하세요.

문제 3. 분석작업 총 20점 (각 10점 · 부분점수 없음)

※ 하나라도 조건을 틀리거나 위치가 어긋나면 해당 문제 점수(10점)가 전부 감점됩니다.

  1. [분석작업-1] 목표값 찾기 (10점): 분석작업-1 시트(4월 스마트폰 매출 현황)에서 순이익(E6)이 20,000,000이 되도록 판매수량(B4)을 변경하는 목표값 찾기를 실행하세요.
  2. [분석작업-2] 데이터 통합 (10점): 분석작업-2 시트에서 [표1](서울, A2:D6), [표2](경기, F2:I6), [표3](인천, A9:D13)의 1~3월 영업실적을 [표4] 수도권 영업실적(F9:I13) 영역에 합계로 통합하세요.

문제 4. 기타작업 (매크로 · 차트) 총 20점 (부분점수 있음)

1. [매크로작업] (10점 · 각 5점, 기록 3점 + 연결 2점)

  1. 매크로작업 시트의 G4:G13 영역에 각 학생의 총점(국어~과학탐구 합계)을 계산하는 매크로를 기록하고, 시트 내 양식 단추/도형에 연결하세요.
  2. A3:G3 머리글 영역에 서식(채우기 색 또는 글꼴 등)을 지정하는 매크로를 기록하고, 시트 내 도형/단추에 연결하세요.

2. [차트작업] (10점 · 5문항 각 2점)

차트작업 시트(1분기 보드게임 매출 현황)에 삽입된 차트에 아래 5가지 작업을 수행하세요.

  1. 차트 제목을 추가하고 적절한 제목 텍스트를 입력하세요.
  2. 차트 종류를 가로 막대형(barChart) 또는 지정된 막대형 계열로 변경하세요.
  3. 범례 위치를 위쪽(t) 또는 아래쪽(b)으로 변경하세요.
  4. 세로(값) 축의 눈금(최솟값/최댓값/주 단위)을 설정하세요.
  5. 차트 계열에 데이터 레이블 값이 표시되도록 설정하세요.
